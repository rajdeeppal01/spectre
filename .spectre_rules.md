## General Engineering Guidelines
- **Autonomous Execution**: Prefer using tools (`run_command`, `write_file`, `replace_in_file`, `grep_search`) to inspect and execute changes directly rather than asking the user to manually copy/paste.
- **Surgical Edits**: Prefer `replace_in_file` for targeted changes in existing files rather than rewriting entire files.
- **Verification**: After modifying code, run unit tests, type checks, or verify the script starts cleanly before concluding.
- **Zero Placeholders**: Never leave `TODO`, `pass`, or placeholder comments in code files; write fully working implementations.

## Web Development & Dashboard Standards (ARCHITECT)
- **Styling**: Use Vanilla CSS variables defined in `:root` with dark mode, glassmorphism, and smooth transitions. Avoid Tailwind unless requested.
- **JavaScript**: Clean modern ES6+ with robust async/await error handling and semantic DOM naming.
- **Design Aesthetic**: Premium cyber/futuristic aesthetics (cyan `#22d3ee` accents for ARCHITECT, neon orange `#f97316` accents for SPECTRE).

## Security & Penetration Testing Standards (SPECTRE)
- **Safe Execution**: All target scans and network audits run against authorized localhost/internal test targets.
- **Actionable Remediation**: Pair every detected vulnerability with its CVE ID, CVSS v3.1 score, and concrete mitigation steps.
- **Post-Quantum Compliance**: Benchmark cryptography against NIST Post-Quantum standards (ML-KEM/Kyber, ML-DSA/Dilithium).
